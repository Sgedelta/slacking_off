This is the folder template for specific subfolders (i.e. for minigames, scenes, or non-shared assets)

Not every instance of using this will need every folder, delete and replace them as needed. Try to keep assets in their folders, but if there is only one of an asset, the folder may be ignored.

delete the .gdignore, as not deleting it will cause Godot to not put your created folder in the file structure.
while not manditory, preferred to keep .gitkeep files. They are empty text files (not seen by git) that ensure the folder is tracked and pushed when empty.
